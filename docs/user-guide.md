## 快速开始

### 第一步：注册账号

1. 访问 http://localhost:5173
2. 点击"注册"按钮
3. 填写用户名、邮箱和密码
4. 完成注册并登录

### 第二步：上传数据集

1. 进入"数据集管理"页面
2. 点击"上传数据集"按钮
3. 填写数据集信息：
   - 名称：数据集名称
   - 格式：选择 YOLO、COCO 或 VOC 格式
   - 描述：数据集说明
4. 上传 ZIP 压缩包
5. 等待数据集处理完成

### 第三步：创建训练任务

1. 进入"训练管理"页面
2. 点击"创建训练"按钮
3. 配置训练参数：
   - 任务名称
   - 模型版本（YOLOv5/v8/v9/v10）
   - 选择数据集
   - 训练参数（epochs、batch_size 等）
4. 点击"开始训练"

### 第四步：查看训练进度

1. 在训练列表中找到正在训练的任务
2. 点击查看详情
3. 实时查看：训练进度、Loss 曲线、mAP 指标、训练日志

### 第五步：测试模型

1. 训练完成后，进入"测试中心"
2. 选择训练好的模型
3. 上传测试图片
4. 查看检测结果（检测框、类别、置信度）

## 数据集管理

### 支持的数据格式

#### YOLO 格式

```
dataset/
├── images/
│   ├── train/
│   │   ├── image1.jpg
│   │   └── image2.jpg
│   └── val/
│       ├── image3.jpg
│       └── image4.jpg
├── labels/
│   ├── train/
│   │   ├── image1.txt
│   │   └── image2.txt
│   └── val/
│       ├── image3.txt
│       └── image4.txt
└── dataset.yaml
```

**dataset.yaml 示例：**
```yaml
train: ./images/train
val: ./images/val

nc: 3
names: ['person', 'car', 'dog']
```

**标注格式（每行一个目标）：**
```
class_id x_center y_center width height
0 0.5 0.5 0.3 0.4
1 0.2 0.3 0.1 0.2
```

#### COCO 格式

```json
{
  "images": [
    { "id": 1, "file_name": "image1.jpg", "width": 640, "height": 480 }
  ],
  "annotations": [
    {
      "id": 1,
      "image_id": 1,
      "category_id": 0,
      "bbox": [100, 150, 200, 250],
      "area": 50000,
      "iscrowd": 0
    }
  ],
  "categories": [
    { "id": 0, "name": "person" }
  ]
}
```

### 上传数据集

1. 将数据集打包成 ZIP 文件
2. 确保目录结构符合规范
3. 在"数据集管理"页面上传
4. 等待处理完成

### 数据集状态

| 状态 | 说明 |
|------|------|
| uploading | 上传中 |
| processing | 处理中（解压、验证） |
| ready | 就绪，可用于训练 |
| error | 处理失败 |

## 模型训练

### 支持的模型版本

| 模型 | 特点 | 推荐场景 |
|------|------|---------|
| YOLOv5n | 轻量级，速度快 | 移动端部署 |
| YOLOv5s | 平衡速度和精度 | 通用场景 |
| YOLOv5m/l/x | 大模型 | 高精度需求 |
| YOLOv8n | 最新轻量级 | 移动端部署 |
| YOLOv8s | 最新平衡型 | 通用场景 |
| YOLOv8m/l/x | 大模型 | 高精度需求 |
| YOLOv9c | 高效架构 | 资源受限场景 |
| YOLOv9e | 增强版 | 更高精度 |
| YOLOv10n/s | 最新轻量级 | 实时检测 |
| YOLOv10m/b/l/x | 大模型 | 高精度需求 |

### 训练参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| epochs | 100 | 训练轮数 |
| batch_size | 16 | 批量大小 |
| img_size | 640 | 输入图片尺寸 |
| learning_rate | 0.01 | 学习率 |
| device | 0 | GPU 编号（"cpu" 使用 CPU） |
| workers | 8 | 数据加载线程数 |
| patience | 50 | 早停轮数 |
| resume | false | 是否断点续训 |
| pretrained_weights | null | 预训练权重路径 |
| augment | true | 数据增强 |

### 创建训练任务

**方式一：Web UI**

1. 点击"训练管理" → "创建训练"
2. 填写表单：
   ```
   任务名称：yolov8n-custom
   模型版本：YOLOv8n
   数据集：my-dataset
   训练轮数：100
   批量大小：16
   图片尺寸：640
   ```
3. 点击"开始训练"

**方式二：API**

```python
import requests

data = {
    "name": "yolov8n-custom",
    "model_version": "yolov8n",
    "dataset_id": "dataset-uuid",
    "config": {
        "epochs": 100,
        "batch_size": 16,
        "img_size": 640,
        "learning_rate": 0.01
    }
}

response = requests.post(
    "http://localhost:8000/api/v1/training/",
    json=data,
    headers={"Authorization": "Bearer your_token"}
)
print(response.json())
```

### 训练状态

| 状态 | 说明 |
|------|------|
| pending | 等待中 |
| queued | 已入队 |
| running | 训练中 |
| completed | 训练完成 |
| failed | 训练失败 |
| cancelled | 已取消 |

### 监控训练进度

进入训练详情页面，可查看：
- **训练进度**：百分比进度条
- **Loss 曲线**：训练损失和验证损失
- **mAP 指标**：mAP50、mAP50-95 变化趋势
- **训练日志**：详细日志输出

### 停止训练

在训练详情页点击"停止训练"按钮，仅 pending/queued/running 状态的训练可停止。

## 模型对比

### 选择模型进行对比

1. 进入"模型对比"页面
2. 点击"新建对比"
3. 选择要对比的模型（至少 2 个）
4. 选择测试数据集
5. 点击"开始对比"

### 对比指标说明

| 指标 | 说明 | 参考范围 |
|------|------|----------|
| mAP50 | IoU=0.5 时的平均精度 | 越高越好，≥0.5 为良好 |
| mAP50-95 | IoU=0.5:0.95 的平均精度 | 越高越好，≥0.3 为良好 |
| Precision | 精确率 | 越高越好 |
| Recall | 召回率 | 越高越好 |
| F1 Score | 精确率和召回率的调和平均 | 越高越好 |
| FPS | 每秒推理帧数 | 越高越好，≥30 为实时 |
| 模型大小 | 模型文件体积 | 根据部署场景选择 |

> 💡 **提示**：建议在同一测试集上对比模型，以确保结果的公平性。

## 超参搜索

超参搜索功能帮助自动找到最优的训练超参数组合。

### 配置搜索空间

1. 进入"超参搜索"页面
2. 点击"新建搜索任务"
3. 配置基础信息：任务名称、数据集、基础模型
4. 配置搜索空间：

```yaml
search_space:
  learning_rate:
    type: log_uniform
    min: 0.0001
    max: 0.1
  batch_size:
    type: choice
    values: [8, 16, 32, 64]
  epochs:
    type: int_uniform
    min: 50
    max: 300
```

**参数类型说明：**

| 类型 | 说明 | 适用场景 |
|------|------|----------|
| `uniform` | 均匀采样 | 连续值参数 |
| `log_uniform` | 对数均匀采样 | 学习率等 |
| `int_uniform` | 整数均匀采样 | epochs、workers |
| `choice` | 离散选择 | 优化器、模型版本 |

### 选择搜索算法

| 算法 | 说明 | 推荐场景 |
|------|------|----------|
| **随机搜索** | 随机采样参数组合 | 快速探索 |
| **贝叶斯优化** | 基于历史结果智能推荐 | 搜索空间较大 |
| **网格搜索** | 遍历所有参数组合 | 参数较少 |

### 查看搜索结果

搜索完成后查看：
- **试验列表**：每次试验的参数和指标
- **最优参数**：最佳参数组合和对应指标
- 可直接基于最优参数创建正式训练任务

## 模型部署

### 支持平台

| 平台 | 说明 | 适用场景 |
|------|------|----------|
| **ONNX Runtime** | 通用推理引擎 | CPU/GPU 通用部署 |
| **TensorRT** | NVIDIA GPU 加速 | NVIDIA GPU 服务器 |
| **TorchServe** | PyTorch 官方服务 | PyTorch 生态 |

### 创建部署

1. 进入"部署管理"页面
2. 点击"新建部署"
3. 选择模型和部署平台
4. 配置参数：
   - 端口
   - Worker 数量
   - 批量大小
   - 是否使用 GPU
5. 点击"开始部署"

### 部署状态

| 状态 | 说明 |
|------|------|
| 🟡 pending | 等待部署 |
| 🟡 deploying | 部署中 |
| 🟢 running | 运行中 |
| ⚫ stopped | 已停止 |
| 🔴 failed | 部署失败 |

### 监控部署

在部署详情页可查看：
- 健康状态
- 运行时长
- 请求计数
- 平均延迟

## 常见问题

### Q1: 训练速度很慢怎么办？

**解决方案：**
```json
{
  "config": {
    "device": "0",
    "workers": 8,
    "img_size": 416,
    "batch_size": 32
  }
}
```

### Q2: 模型精度不高怎么办？

1. 增加数据量和数据增强
2. 检查并修正标注错误
3. 增加训练轮数（epochs）
4. 使用更大的模型（如 YOLOv8m 或 YOLOv8l）
5. 使用超参搜索功能自动调优

### Q3: 如何选择合适的模型？

| 场景 | 推荐模型 |
|------|---------|
| 实时检测（移动端） | YOLOv8n / YOLOv10n |
| 通用场景 | YOLOv8s / YOLOv10s |
| 高精度需求 | YOLOv8m / YOLOv8l |
| 最高精度 | YOLOv8x |
| 资源受限 | YOLOv9c |

### Q4: 训练中断了怎么办？

在创建训练时设置 `resume: true`，指定上次的 checkpoint 文件路径，即可从断点继续训练。

### Q5: 如何导出模型？

在模型详情页点击"导出"，选择目标格式（ONNX / TensorRT / TorchScript 等），导出为异步任务。
