# 更新日志

> YOLO Trainer 版本更新记录

本项目遵循 [语义化版本](https://semver.org/) 规范。

## [1.0.0] - 2026-06-22

### ✨ 新增功能

#### 核心训练
- **多版本 YOLO 训练**: 支持 YOLOv5、YOLOv8、YOLOv9、YOLOv10 多个版本的模型训练
- **训练器抽象架构**: 基于 `BaseTrainer` 抽象基类，通过策略模式支持不同 YOLO 版本
- **异步任务队列**: 基于 Celery + Redis 的异步训练任务调度
- **训练参数配置**: 支持 epochs、batch_size、img_size、learning_rate、optimizer、patience 等完整参数
- **断点续训**: 支持从 checkpoint 恢复训练
- **训练进度监控**: 实时查看训练状态、Loss 曲线、mAP 指标

#### 模型管理
- **模型版本控制**: 自动保存训练产出的模型，支持版本历史管理
- **标签系统**: 为模型添加自定义标签（如 production、staging、best）
- **模型导出**: 支持导出为 ONNX、TorchScript、TensorRT、CoreML、TFLite、PaddlePaddle 格式
- **模型下载**: 直接下载模型权重文件
- **模型删除**: 删除模型及其关联文件

#### 数据集管理
- **ZIP 上传**: 支持上传 ZIP 格式的数据集压缩包
- **多格式支持**: 兼容 YOLO、COCO、VOC 三种标注格式
- **数据集统计**: 自动解析并统计类别分布、图片数量
- **异步处理**: 上传后异步解压和验证

#### 测试中心
- **单图推理**: 上传单张图片，实时返回检测结果
- **批量推理**: 支持多张图片同时检测
- **检测结果可视化**: 返回检测框坐标、类别、置信度
- **推理时间统计**: 记录每张图片的推理耗时
- **结果图片**: 支持获取带检测框标注的结果图片

#### 模型对比
- **多模型对比**: 支持 2-6 个模型同时对比
- **多维指标**: 对比 mAP、Precision、Recall、F1、推理速度、模型大小
- **可视化展示**: 指标表格、柱状图、雷达图对比

#### 超参搜索
- **搜索算法**: 支持随机搜索、贝叶斯优化、网格搜索
- **搜索空间配置**: 支持 uniform、log_uniform、int_uniform、choice 等参数类型
- **试验管理**: 查看每次试验的参数和结果
- **最优结果**: 自动记录最优参数组合和最佳指标

#### 模型部署
- **多平台部署**: 支持 ONNX Runtime、TensorRT、TorchServe
- **部署配置**: 可配置端口、Worker 数量、批大小、GPU 等
- **状态监控**: 查看部署健康状态、运行时长、请求计数、平均延迟
- **部署管理**: 创建、查看、停止部署

#### 团队管理
- **团队创建**: 创建团队，创建者自动成为 Owner
- **成员管理**: 邀请/移除成员，仅 Owner 可操作
- **角色权限**: 支持 owner、member 角色

#### 活动日志
- **操作审计**: 记录用户的所有操作（创建、更新、删除等）
- **筛选过滤**: 支持按用户、资源类型、时间范围筛选
- **分页查询**: 支持分页浏览历史记录

#### 用户认证
- **用户注册**: 用户名 + 邮箱 + 密码注册
- **JWT 认证**: 基于 JWT 的无状态认证
- **密码安全**: bcrypt 哈希加密存储
- **路由守卫**: 前端 JWT Token 自动附加和过期跳转

#### 系统架构
- **FastAPI 异步框架**: 高性能异步 API 服务
- **SQLAlchemy Async**: 异步数据库操作
- **SQLite 开发模式**: 开箱即用，无需额外数据库
- **安全中间件**: CSP 头、SQL 注入检测、路径穿越检测
- **限流器**: Redis 滑动窗口限流（已实现，待激活）
- **监控指标**: API 请求计数、响应时间、错误率统计
- **健康检查**: `/health` 端点
- **CORS 配置**: 环境变量控制跨域白名单

#### 前端
- **Vue 3 + Naive UI**: 现代化响应式 Web 界面
- **Pinia 状态管理**: 集中式状态管理
- **Vue Router**: 路由懒加载 + JWT 守卫
- **15 个页面**: 仪表盘、训练管理(3页)、模型管理(2页)、数据集、测试、对比、部署、超参搜索、团队、活动日志、登录

### 🔧 技术改进

- 数据库连接池配置：pool_size=10, max_overflow=20, pool_recycle=1800s
- 数据库操作重试机制：指数退避，最多 3 次重试
- 请求指标中间件：自动记录 API 请求耗时和状态码
- 结构化日志：DEBUG 模式下彩色输出，生产模式 JSON 格式
