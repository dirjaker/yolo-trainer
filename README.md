# YOLO 模型训练平台

> YOLO 视觉模型训练、版本控制与测试一体化平台：支持 YOLOv5/v8/v9/v10

`Python` `FastAPI` `Vue.js` `PyTorch`

---

## ✨ 功能特性

- YOLOv5/v8/v9/v10支持
- 模型训练
- 版本控制
- 测试评估
- 数据集管理

## 🚀 快速开始

```bash
# 克隆项目
git clone https://github.com/dirjaker/yolo-trainer.git
cd yolo-trainer

# 创建虚拟环境
conda create -n yolo-trainer python=3.12 -y
conda activate yolo-trainer

# 安装依赖
pip install -r requirements.txt

# 运行项目
python main.py
```
